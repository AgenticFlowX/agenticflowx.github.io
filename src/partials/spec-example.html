# Find the right project.

## The problem
As the project list grows, people spend too long finding
their work. Add search to the existing project list.

## Requirements
| ID   | Requirement |
| ---- | ----------- |
| FR-1 | Filter projects by name, ignoring letter case. |
| FR-2 | Show “No projects found” when nothing matches. |
| FR-3 | Clearing the search restores the full project list. |

## Acceptance criteria
- Searching “garden” finds “Garden Planner”.
- An unmatched query shows the empty state.
- Clearing the field restores every project.

## Out of scope
Searching file contents, fuzzy matching, and saved searches.
