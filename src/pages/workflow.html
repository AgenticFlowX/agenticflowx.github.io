Install

Add AFX to the agent you already use.

Every route installs the same skills and produces the same Markdown. Pick one route per agent.

Claude Code · plugin

Inside Claude Code

/plugin marketplace add AgenticFlowX/afx
/plugin install afx@afx

Or from a terminal:

claude plugin marketplace add AgenticFlowX/afx
claude plugin install afx@afx --scope user

Reload plugins, then run /afx:hello. Plugin commands are namespaced: /afx:spec, /afx-dev:tdd.

One route per agent

You can use the CLI for Codex and the plugin for Claude in the same project. Don’t load the same skills twice into a single agent.

Where it’s been tested

Claude Code: heavily tested. Codex and GitHub Copilot: tested. Cline, AugmentCode, KiloCode, and OpenCode follow the same skills format but haven’t been verified.

Operating systems

The installer is tested on macOS and Linux/WSL. On Windows, use Git Bash. Node.js 18+ is optional and speeds up structured document reads.

Claude Desktop & Cowork

The same skills in the Claude app.

Add the AgenticFlowX marketplace from its GitHub repository.

  1. Open Customize → Plugins → Add plugin → Add marketplace → Add from a repository.
  2. Enter AgenticFlowX/afx and select Sync.
  3. Open Afx, select Add, and check that it’s enabled.

An auto-sync notice may appear. It’s about automatic updates, which need Claude’s GitHub App to have access to the repository; the first import still works without it. This is the AgenticFlowX-hosted marketplace, separate from Anthropic’s reviewed directory. Available controls depend on your Claude app and account.

Approval and checks

Approved means checked. Done means verified.

Documents start as Draft and move forward only on purpose. Tasks need two sign-offs, and the checks say plainly what they can’t prove.

  1. Draft
  2. Validate
  3. Review
  4. Approved
  5. Code
  6. Verify
  7. Agent ✓
  8. Human ✓
Approve
Runs structural validation and a review, and is blocked while critical issues remain. The approved spec becomes the reference for design, tasks, and code.
Change it
Edit an approved section and it, and everything after it, returns to Draft with a version bump. Living documents describe the present; the history goes in the journal.
Two sign-offs
Work Sessions carry the agent’s tick and a human’s. The human box is never ticked before the agent’s.
/afx-task verify
Checks one task against its spec: the files exist, the @see links resolve, no TODOs remain, and the session was logged.
/afx-check
path traces a feature from UI to database and flags mocks and placeholders. trace and links audit annotations and cross-references. Also schema, deps, and coverage.
/afx-report
Read-only metrics: code with no @see link, which requirements have code, and specs that have gone stale.
Limits
These are text checks run by your agent. They don’t run builds or tests, and they don’t prove the code is correct. Your tests and your review are the final word.

Session continuity

The next session starts where this one stopped.

Chat history disappears. The journal and context bundles don’t. Any agent can pick up the work from the files.

journal.md
An append-only record of decisions and discussions, each with its own ID.
/afx-session capture
Records the exact prompt behind a decision, with the agent, model, and affected IDs.
/afx-session promote
Turns a discussion into an ADR or a spec change.
/afx-context save · load
Hands spec state, task progress, and open questions to another agent.
/afx-next
Reads git state, tasks, and sessions, and suggests the single next command.

Questions

Before you install.

Do I need the VS Code extension?

No. The skills run in any compatible agent. The extension adds a coding chat, document actions in the Previewer, and project panels on top of the same files.

Is there an AFX account, server, or API key?

No. The skills are files in your repository and the output is Markdown. Your agent and your model provider are the only services involved.

Does a spec stop an agent from drifting?

It makes the intended work explicit and easier to review. Agents can still misread it or miss a requirement, which is why AFX has verification steps and a human sign-off.

Can I keep my own skills?

Yes. AFX uses the open Agent Skills format, so your agent loads it alongside your other project and personal skills.

Prefer to see the plan while you work?

The VS Code extension renders these documents with actions, progress, and the code they point to.
