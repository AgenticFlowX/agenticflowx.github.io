Blueprint · Explore mode

Understand a repository before you change it.

Inspect a project, review findings and evidence gaps, then save a portable blueprint.json and blueprint.md. Check Changes compares locally; Update and Rebuild produce proposals to review. Start a Sprint from selected findings when you’re ready.

Blueprint findings describe the sources that were inspected. They don’t prove that behaviour was executed, and changed or missing evidence stays visible as a limitation.

The AFX Previewer

Your Markdown, as a document you can work from.

Open any Markdown file in the Previewer from the editor title bar. It sits beside the source, updates as you type, and adds actions for the document you’re reading. The file stays plain Markdown in your repository.

Draft or Auto

Actions that create content draft a command into the chat for you to edit first. Read-only checks run automatically. Each button says which.

Quality Pulse

A scorecard for Strategy, Structure, Clarity, and Completeness, each rated good, watch, or gap.

Refinement Coach

Suggestions that say why a gap matters, show the evidence, and offer a one-click next step.

Section actions

Open Questions get Answer, Resolve, and Journal. Acceptance and proof sections get Add proof. Decisions and risks get Journal and Refine.

Writes back to the file

Tick a task, or the agent and human sign-off for a work session, and the Markdown file changes.

Made for reading

An outline, jump links for IDs like FR-1 and DES-API, and saved preferences for width, size, paper tone, font, and focus.

@see in your code

Ask the code why it exists.

A comment like @see docs/specs/search/spec.md [FR-1] becomes a live link in the editor.

CodeLens
Open spec and Open design, right above the annotated code.
Hover
Preview the requirement row or design section without leaving the file.
⌘/Ctrl-click
Go to the definition of [FR-X], [DES-X], or task [X.Y].
Autocomplete
Paths and IDs complete as you type after @see. An Add @see Link command does it from the context menu.

Broken or missing links aren’t shown as live editor errors. Check them on demand with Verify Traceability or /afx-check trace. A link records intent; tests and review show whether the code meets it.

Everyday details

Settings worth knowing about.

Project trust

afx.pi.projectTrust asks before loading a project’s own skills and settings. Choose ask, trust, or ignore.

More skills

Add folders with afx.skills.extraPaths, and exclude tools with afx.pi.excludedTools.

Appearance

The Meridian theme with seven style treatments, and afx.experimental.workbenchHiddenViews to hide tabs.

Networks and proxies

Route provider traffic through afx.network.httpProxy. API keys are kept in VS Code’s secret storage.

Modified files

afx.chat.autoOpenModifiedFiles opens files as the agent changes them. Off by default.

Telemetry

The extension’s views use Microsoft Clarity, on by default. It follows VS Code’s telemetry setting and Do Not Track, and afx.telemetry.enabled turns it off.
