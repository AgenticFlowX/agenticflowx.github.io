# Provider logos

Single-colour SVG icons from [Simple Icons](https://simpleicons.org) (CC0 1.0), downloaded from
`cdn.jsdelivr.net/npm/simple-icons@latest/icons/<slug>.svg` on 2026-11-22. Each file contains only
`<svg>`, `<title>`, and `<path>`.

The icons are free to use, but the brands they represent are trademarks of their owners. They identify
which providers AgenticFlowX can connect to; they do not imply endorsement. Simple Icons has no icon
for Ant Ling, Baseten, Cerebras, Fireworks, Groq, Radius, Together AI, xAI, or Z.ai, so those appear as text.
